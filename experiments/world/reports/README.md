# Reports

Store concise experiment notes, metric tables, and post-run interpretation for
the world-model track.

Each report should state:

- objective family,
- literature status when the objective or anti-collapse mechanism changes,
- command run,
- checkpoint/output directory under `models/world/` or `results/`,
- Part 1 metrics,
- Part 2 metrics when applicable,
- decision: continue, modify, or kill.

For Part 1 reports, do not treat predictor-target cosine or MSE as sufficient.
Include retrieval, effective rank, variance, singular spectrum, redundancy, and
mask-artifact checks for the representation surface being evaluated.
